Code Week 2026

臺東大學資訊管理學系學生會第一屆【編程周】活動公告。 本頁提供活動簡介、時間地點與相關注意事項，請同學留意後續更新。

活動簡介

Code Week 2026 為資訊管理學系學生會推出的程式主題活動。 內容以學習、交流與實作為主，適合對程式設計、工具應用或技術分享有興趣的同學參與。
