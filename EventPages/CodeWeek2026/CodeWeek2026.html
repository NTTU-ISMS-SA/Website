Code Week 2026

臺東大學資訊管理學系學生會第一屆【編程周】活動公告。

活動簡介

Code Week 2026 為資訊管理學系學生會推出的程式編寫活動。

無論你是剛接觸程式的新手，還是正在鑽研底層架構的狂熱者，
Code Week 2026 都歡迎你。

讓我們打開編輯器，面對真實的程式碼，我們在 Code Week 見。

立即報名 前往活動頁面

時間地點

  • 活動時間2026/06/01 ~ 2026/06/07
  • 活動地點ZeroJudge 與 GitHub
  • 主辦單位臺東大學資訊管理學系學生會

重點注意事項

  • 需要 GitHub 帳號
  • 需要 Git 基礎操作技能
  • 提交格式需嚴格按照規定
